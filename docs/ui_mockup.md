# UI Макет (текстовый)

## Панель фильтров (слева / сверху):
- [Выбор региона] (выпадающий список)
- [Выбор типа показателя] (social, climate, economic...)
- [Выбор конкретного показателя]
- [Выбор года или диапазона лет]

## Основная панель:
- График: линия или столбцы
- Таблица: значения по выбранным фильтрам
- Tooltip: значение + единица измерения
- Блок описания показателя
