## Описание ERD-модели

### 1. `regions`

Хранит информацию о регионах РФ.

- `id` — Уникальный идентификатор региона (тип: SERIAL, первичный ключ).
- `name` — Название региона (например, "Республика Алтай").
- `code` — Код региона (например, "22").
- `type` — Тип региона ("республика", "край", "область").

### 2. `years`

Содержит информацию о годах, для которых собираются данные.

- `id` — Уникальный идентификатор года.
- `year` — Числовое значение года (например, 2022).

### 3. `indicator_types`

Типы индикаторов по категориям.

- `id` — Уникальный идентификатор типа.
- `name` — Категория (например, "social", "climate", "economic").
- `description` — Описание категории индикаторов.

### 4. `indicators`

Все показатели, включённые в анализ.

- `id` — Уникальный идентификатор показателя.
- `type_id` — Внешний ключ на `indicator_types.id`.
- `name` — Название показателя (например, "Смертность").
- `unit` — Единица измерения (например, "чел", "мм").
- `theme` — Тематическая группа (например, "Демография").
- `subcategory` — Подкатегория (например, "Смертность до 1 года").
- `description` — Описание показателя.

### 5. `data_sources`

Источники данных, откуда загружаются индикаторы.

- `id` — Уникальный идентификатор источника.
- `name` — Название источника (например, "Росстат").
- `url` — Ссылка на источник (если есть).
- `organization` — Организация-источник.
- `date_collected` — Дата сбора данных.
- `data_status` — Статус данных ("официальные" или "оценочные").
- `notes` — Примечания к источнику.

### 6. `indicator_values`

Основная таблица значений показателей по регионам и годам.

- `id` — Уникальный идентификатор.
- `indicator_id` — Внешний ключ на `indicators.id`.
- `region_id` — Внешний ключ на `regions.id`.
- `year_id` — Внешний ключ на `years.id`.
- `value` — Значение показателя.
- `source_id` — Внешний ключ на `data_sources.id`.
- `method` — Метод получения (например, "API", "Excel").
- `is_forecasted` — Логическое значение: является ли прогнозом.

### 7. `indicator_relations`

Описание влияния одного показателя на другой.

- `id` — Уникальный идентификатор.
- `cause_id` — Влияющий показатель (внешний ключ `indicators.id`).
- `effect_id` — Зависимый показатель.
- `influence_type` — Тип влияния ("положительное" или "отрицательное").
- `strength` — Сила влияния ("высокая", "средняя", "слабая").
- `description` — Комментарий.

### 8. `events`

Описание значимых событий, повлиявших на регион.

- `id` — Уникальный идентификатор.
- `name` — Название события (например, "Паводок в Республике Алтай").
- `region_id` — Ссылка на регион, где произошло событие.
- `year_id` — Год события.
- `event_type` — Тип события ("пожар", "наводнение", "ЧС").
- `impact` — Последствия (например, "Ущерб", "Эвакуация").
- `description` — Подробное описание события.

---

## Связи между таблицами (ERD)

- Один `region` может иметь много `indicator_values` и `events`.
- Один `indicator` может участвовать как причина или следствие в таблице `indicator_relations`.
- `indicator_values` объединяет показатели, регионы, годы, источники и методы.
