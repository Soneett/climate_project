# Пример репозитория на основе SQLAlchemy и FastAPI

Основные файлы:

- [run.bat](run.bat) - построение и запуск контейнеров (БД и бэкенд)
- [create_tables.py](create_tables.py) - скрипт для (пере)создания таблиц в БД
- [fill_data.py](fill_data.py) - заполнение БД данными
- [query_examples.py](query_examples.py) - выполнение запросов к БД через репозиторий

Бэкенд:

- http://localhost:8080/docs
