# Формат фронтенд-данных (web/src/constants)

## Что используется сейчас

- `frontend/web/src/constants/contentBlocks.js` — задаёт, какие показатели объединяются на одном графике и какой тип графика используется (`line`, `pie`, `barB`).
- `frontend/web/src/constants/navigationMenus.js` — разделы и подпункты меню.
- `frontend/web/src/constants/regions.js` — список регионов.

## Что изменено в api_test

- Страница `api_test/site/index.html` теперь строит графики **в парадигме фронтенда**:
  - несколько связанных показателей на одном графике (например, доходы/расходы),
  - корректный тип графика (причины смертности — `pie`),
  - учёт подпоказателей через `subtype`.
- Если во фронтенд-логике нужен агрегированный ряд, используется подпоказатель `всего`.
- Добавлена интерактивная фильтрация серий на каждом графике.
- Добавлен фильтр по годам (`Год от` / `Год до`) для всех линейных и круговых графиков.
- Половозрастная пирамида остаётся отдельным API-запросом.

## Проверка покрытия входных файлов indicator_values

Проведена проверка всех JSON в `old/backend/data/indicator_values`: для каждой строки валидированы обязательные данные для вставки (indicator, region, source, year/value). По текущим файлам: `1068/1068` строк пригодны к загрузке.
