# Формат фронтенд-данных (web/src/constants)

## Что используется сейчас

- `frontend/web/src/constants/contentBlocks.js` — основной источник структуры графиков.
  - Блоки сгруппированы по разделам (`s1`, `s2`, `s3`, ...).
  - Для линейных графиков формат: `chartData.labels + chartData.datasets[{name,data}]`.
  - Для круговых и таймлайновых графиков формат: `pieData.timelineLabels + pieData.timelineData`.
  - Для половозрастной пирамиды формат: `barBData.categories + barBData.timelineData`.
- `frontend/web/src/constants/navigationMenus.js` — названия и иерархия разделов.
- `frontend/web/src/constants/regions.js` — справочник регионов для UI.

## Что изменено в api_test

- В `api_test/site/index.html` графики строятся **для всех доступных показателей** из backend API.
- Показатель и подпоказатель учитываются отдельно:
  - в БД один базовый показатель (`indicators.name`),
  - конкретные варианты идут через `subtype` и отображаются как отдельные серии.
- Для каждого графика добавлена интерактивная фильтрация серий (чекбоксы).
- Для графиков добавлен фильтр по годам (`Год от` / `Год до`).
- Для блока демографии `Причины смертности` отображаются как `pie`.
- Пирамида населения остаётся отдельным API-запросом.

Это позволяет проверять отрисовку на реальных данных backend API и отслеживать корректность связки показатель/подпоказатель.
