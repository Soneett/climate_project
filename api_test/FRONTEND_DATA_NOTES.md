# Формат фронтенд-данных (web/src/constants)

## Что используется сейчас

- `frontend/web/src/constants/contentBlocks.js` — основной источник структуры графиков.
  - Блоки сгруппированы по разделам (`s1`, `s2`, `s3`, ...).
  - Для линейных графиков формат: `chartData.labels + chartData.datasets[{name,data}]`.
  - Для круговых и таймлайновых графиков формат: `pieData.timelineLabels + pieData.timelineData`.
  - Для половозрастной пирамиды формат: `barBData.categories + barBData.timelineData`.
- `frontend/web/src/constants/navigationMenus.js` — названия и иерархия разделов.
- `frontend/web/src/constants/regions.js` — справочник регионов для UI.

## Что изменено в api_test

- В `api_test/site/index.html` убран выбор показателей по ключевым словам.
- Для каждого графика задан фиксированный список `indicatorNames` (явный маппинг график -> показатели).
- Добавлен интерактивный фильтр по сериям (чекбоксы) для каждого графика.
- Пирамида населения остаётся отдельным API-запросом, как и в основном фронтенде.

Это позволяет проверять отрисовку на реальных данных backend API и приближает тестовый стенд к структуре `contentBlocks.js`.

- Для блока демографии график «Причины смерти» в `api_test` переведён в `pie` (по аналогии с фронтенд-представлением причин как структуры, а не динамики).
