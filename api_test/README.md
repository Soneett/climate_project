# API tests: интерактивный сайт с графиками из backend

`api_test` теперь содержит локальный сайт, где графики строятся так же интерактивно, как на фронтенде (ECharts), но с данными из развернутой БД через backend API.

## Запуск

```bash
python api_test/charts_site.py --host 127.0.0.1 --port 8090
```

Открыть в браузере:
- `http://127.0.0.1:8090/site/index.html`

## Что реализовано

- **Половозрастная пирамида** из `GET /analytics/population_pyramid`.
- Корректная сортировка возрастных кодов (от backend):
  - конкретные возраста (`1`, `2`, `3`),
  - интервалы (`1-5`, `5-12`),
  - группы вида `65+`.
- **Страничный режим**: пользователь не задает `indicator_ids` вручную.
  - На каждой странице автоматически выбираются подходящие показатели по тематике/ключевым словам.
  - Для групп строятся **line chart** и **pie chart**.
- Интерактивность: легенда, tooltip, resize.

## Важно

- Фронтенд проекта не изменяется.
- Все изменения изолированы в `api_test` и backend analytics sorting.
